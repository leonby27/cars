# Фильтры Guazi для будущего импорта

26.09.2026. Текущий массовый запуск работает только в локальный каталог: см. `GUAZI_IMPORT.md`. Марки идут от малочисленных к многочисленным по свежему подсчёту. Production не изменён.

## Базовый фильтр по аналогии с Che168

| Условие | Значение | Где применяется |
|---|---|---|
| Марки | Наш список из 45 марок | Ссылки Guazi по маркам источника; подмарки распознаются в карточках |
| Тип двигателя | Электро, PHEV, EREV/REEV, бензиновый раздел | В ссылке Guazi; бензиновый раздел включает обычные HEV |
| Первая регистрация китайских марок | С 2021 года | В ссылке Guazi |
| Первая регистрация остальных марок | С 2022 года | В ссылке Guazi |
| Цена FOB Horgos | $7 000–100 000 | По подтверждённой USD-котировке публичной экспортной карточки |

Общие числовые пороги читаются из `config/refresh-order.json → filters`, как у Che168. Дополнительные общие ограничения каталога по модельному году и расчётной стоимости под ключ остаются в `config/import-policy.mjs`; это отдельные проверки, не цена Guazi.

**Ценовая политика:** в текущем bulk используется FOB Horgos. Числовые пределы сохранены, но теперь относятся к FOB, а не чистой цене машины. Цену проверяем после чтения карточки; китайский `full_payment` больше не обязателен. Котировка другого порта не подставляется. Ссылки по-прежнему без ценового фильтра.
