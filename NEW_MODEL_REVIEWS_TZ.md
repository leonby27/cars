# ТЗ: новые обзоры моделей

Делать по аналогии с существующими обзорами (`src/model-pages.js` + `src/model-texts/<slug>.js`,
пример — `toyota-corolla`). Данные брать из живой базы, не выдумывать. Slug проверять
на совпадение с уже существующими.

## Три отличия от старых обзоров

1. **Заголовок и H1 — не под копирку.** Раньше все 240 страниц были по одной формуле
   дословно. Чередовать «купить» / «с пробегом» / «цены», добавлять деталь модели.
2. **Не копировать абзац про доставку слово в слово** (раньше был дословно в 238 из
   239 обзоров — выглядит для поисковика как шаблон). Тот же факт — своими словами.
3. **1–2 живые ссылки внутри текста** на смежные страницы каталога (тип топлива,
   кузов, ценовая полоса, растаможка) — в дополнение к автоматическому блоку внизу,
   который не трогать.

## Ловушки

- «Дешевле в оформлении» ловится тестом `ev-duty-copy` — для бензина писать
  «пошлина ниже».
- Пошлина бензина — врезка `DUTY_ICE` / `DUTY_ICE_SHORT`, не электро-формулировки.
- Двойники (Passat/Magotan, Wildlander/RAV4, Inspire/Accord, Atenza/Mazda6,
  Frontlander/Corolla Cross) — называть родство явно.
