# Предварительные цены ABDrive до Москвы

Реализовано 01.10.2026. Независимый серверный расчёт в RUB; не использует итоговые цены, квоты, льготы, курсы или формулу ABCars. Выбор города пока содержит только Москву. Переключатель валюты убран во всех общих компонентах ABDrive.

## Область расчёта

Обычные бензиновые/дизельные автомобили для личного ввоза физлицом, при наличии цены продавца, года, объёма и мощности двигателя. Витрина и подробная карточка используют один `offer`, карточка раскрывает состав затрат и допущения. Сумма округляется вверх до 10 тыс. RUB.

Электромобили и распознаваемые гибриды рассчитываются по исходной цене и подробным характеристикам `technicalSpecs`, а не блокируются целой категорией. Объём в см³ и мощность ДВС берутся из группы Engine, суммарная пиковая мощность электромоторов — из Electric Motor. Системная мощность не подменяет мощность ДВС или сумму электромоторов. Последовательная схема определяется по явному описанию источника (Range Extender / Extended range / EREV / REEV); DHT, E-CVT и другие распознаваемые механические трансмиссии гибрида используют схему параллельного гибрида. Неясный тип остаётся явной причиной недоступности.

Если суммарная 30-минутная мощность известна из исходных данных, используется она. Иначе применяется версионируемый справочник `config/ru-power-reference.mjs`: 31 запись по двигателям и модификациям BYD, Tesla, Kia, Hyundai и Li Auto. У записи есть источник, тип доказательства, годы и ограничения по схеме, приводу, коду/числу моторов, пиковой мощности или батарее. Номинальная мощность производителя и данные импортёра используются только как оценка; они не записываются в поле документальной мощности. Европейские данные Tesla также служат оценкой для ввезённого автомобиля.

При нескольких совместимых записях берётся минимум/максимум их значений. Точная модификация исключает соседние версии; если комплектация неизвестна, остаются все совместимые кандидаты. Год из полного названия модификации имеет приоритет над годом объявления. ДВС: максимальная нетто-мощность из спецификации имеет приоритет над общей максимальной мощностью.

Без совпадения со справочником сохраняются широкие границы от нуля до пиковой электрической мощности; при неизвестном пике параллельного гибрида — до максимальной строки утильсбора. Универсальный коэффициент 45% не применяется: он не подтверждён для всех моделей и может исключать реальное значение из диапазона. EV без любой информации о мощности остаётся недоступен. Новых пользовательских блоков нет; краткое пояснение остаётся в существующей подсказке.

API `inputs.motorPower` содержит `minKw/maxKw`, `method` (document/reference/unknown/not-applicable), версию справочника, идентификаторы записей и источников. Поле `continuousPowerKw` по-прежнему содержит только исходное документальное значение. Изменение версии справочника автоматически меняет версию цен и инвалидирует сохранённый ценовой индекс. Витрина и индекс используют одинаковые поля привода и батареи.

EV и последовательные гибриды: пошлина 15%, акциз по мощности, НДС 22% с суммы таможенной стоимости, пошлины и акциза, затем утильсбор по электрической таблице 2026. Для параллельных гибридов — единая ставка по возрасту/объёму и утильсбор по сумме ДВС и 30-минутной мощности электромоторов. Льготная сумма не распространяется автоматически на любой гибрид. При неизвестной мощности возможная льгота отмечена как условие нижней границы.

В API `range.min/max` — итоговые границы, `totalAmount` — верхняя сумма для совместимости; интерфейс всегда показывает диапазон, если он есть. В строках затрат `amount` — верхняя сумма, `minAmount/maxAmount` присутствуют у неопределённых платежей. Нижний итог округляется вниз, верхний вверх до 10 тыс. RUB. Когда все платежи попадают в одну ставку, возвращается обычная предварительная сумма.

Пример из имеющейся базы: `che168-59495719`, Galaxy M9 2025, 224400 CNY, 1499 см³, ДВС 120 кВт, электромоторы 520 кВт, DHT. Утильсбор 900000–3201600 RUB; итог меняется с курсом и размером доставки. Для сужения этого диапазона нужна запись соответствующей модификации в справочнике либо документальная суммарная 30-минутная мощность.

Год модели — предварительная замена даты выпуска. На границе 3/5 лет берётся больший платёж из возможных для этого календарного года; это отмечается в смете. Объём берётся из объявления в литрах. Документы могут изменить возрастную группу, точный объём и мощность. Расчёт на текущую дату, не обещание ставок на день будущего оформления.

- Курсы: [XML ЦБ РФ](https://www.cbr.ru/scripts/XML_daily.asp). Начальный снимок на 01.10.2026: USD 83.5588, EUR 94.8810, CNY 12.4732, 1000 KRW 61.5127. Запрос не чаще раза в час, таймаут 2.5 с, при ошибке сохраняется датированный снимок; старше 7 суток цены скрываются. На 2027 год расчёт прекращается до обновления правил.

## Рыночная логистика до Москвы

По поручению владельца от 01.10.2026 использованы средние опубликованных тарифов. Источники, расчёт средних и отдельные допущения по зонам сохранены в `docs/research/2026-10-01-ru-delivery-rates/rates.json` относительно корня репозитория. На публичной странице нет дополнительного блока об ориентировочности; форма повторяет ABCars: модель и местоположение, итог и строки пути.

Два основных плеча — арифметические средние открытых предложений; разбивка внутренних расходов и габаритные надбавки содержат допущения, явно записанные в исследовании. Нельзя называть их отдельными подтверждёнными котировками для каждого города. Валютные строки пересчитываются по курсу ЦБ и округляются до 1000 RUB. Крупный кузов определяется длиной от 4950 мм или массой от 2300 кг, в том числе по техническим характеристикам источника. Калькулятор и карточка используют одну функцию `estimateRussianDelivery`. Исходные фиксированные поля `china/korea` оставлены только для совместимости с конфигурацией без `logistics`.
Для цены FOB до Хоргоса или Пусана расходы до этого пункта не начисляются повторно. Покупка и таможенные платежи остаются отдельными строками.

## Проверка и оставшаяся работа

Проверяются пороги пошлины, 160/161 л.с., 3000/3001 см³, возрастные границы, FOB, KRW, сумма строк, отсутствие влияния BY-цен, отказ при устаревших курсах/недостающих данных. Никакие каталожные или клиентские записи BY не меняются.

Сортировка и фильтрация по российской цене включены. Отдельный индекс рассчитывает RUB по текущим исходным данным; при диапазоне используется верхняя сумма, чтобы бюджетная подборка не обещала неизвестную минимальную цену. Индекс не пишет BY-колонки. Справочник расширяется отдельными записями с источниками и ограничениями; неизвестные модификации сохраняют широкий диапазон. Документальные значения и точная дата выпуска уточняют расчёт.
