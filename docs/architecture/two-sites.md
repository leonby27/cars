# abcars.by и abdrive.ru: состояние архитектуры

Обновлено 1 октября 2026 года. Российская версия подготовлена в отдельной рабочей копии `../abdrive-worktree`, чтобы не задеть параллельные изменения главной abcars.by. Это один Git-репозиторий и общие модули, а не второй независимый проект.

Код сохранён локальным коммитом в ветке `codex/abdrive-architecture-20261001`. В основной BY-ветке сохранены параллельные изменения; общий BY-деплой не выполнялся. Единственное намеренно оставленное изменение в AGENTS.md рабочей копии — инструкция соседней задачи о загрузке главной; она не включена в российский коммит.

## Принятые решения

- Общий импорт и факты автомобилей; отдельные предложения, тексты, сервисы и пользовательские данные рынков.
- РФ: RUB, базовый город доставки Москва. Другие города подключаются с тарифами.
- Заявка приходит владельцу; он сам передаёт её выбранному партнёру.
- Общего флага «RU не готов» нет. Каталог работает независимо от будущих расчётов, документов и инструментов.
- Изменения BY не публикуются вместе с RU. Ранее работающий BY-процесс и бизнес-данные сохраняются.

Фото используют общий существующий публичный кэш. Российская композиция интерфейса самостоятельна, но использует общие компоненты фото, пустого состояния, справочник происхождения и факты импорта. Полного переноса всех возможностей BY пока нет: личный кабинет, избранное, журнал, аналитика и сервисы РФ — следующие отдельные изменения.

## Что установлено на сервере

- Сервер: 5.23.48.128, существующий Timeweb.
- Приложение: `/srv/abdrive/current` → `/srv/abdrive/releases/20261001-catalog`.
- Закрытая конфигурация: `/etc/abdrive/environment`, root:abdrive, 0640. Секреты не копируются в код.
- База: `abdrive`, только новые таблицы `site_identity`, `leads`, `lead_notifications`, `market_offers`. Рабочие BY-записи не изменялись.
- Служба: `abdrive.service`, 127.0.0.1:8788; включён автозапуск. BY-служба не перезапускалась: PID 96469, старт 08:49:12 UTC.
- Отдельный HTTP-хост nginx для abdrive.ru/www.abdrive.ru; общая конфигурация проверена перед плавной перезагрузкой nginx.
- Через запросы непосредственно к серверу подтверждены главная, каталог, карточка, порядок покупки, robots, sitemap, отдельный API. На проверке каталог содержал около 134 тысяч активных объявлений.
- Прямой запрос к каталогу не возвращает исходный payload, URL продавца или белорусскую цену. RU-роль не видит таблиц клиентов BY.
- В новой рабочей базе 0 заявок и 0 уведомлений: тестовые обращения туда не создавались, Telegram-сообщения не отправлялись.

При первом подключении выявлена ошибка проверки отсутствующей предыдущей версии в сценарии отката. Исправлена; повторный выпуск r2 успешно проверен. Она затронула только новый ABDrive-процесс. Ограничение в три соединения намеренное: диагностику прав выполняем через администратора в транзакции только для чтения, не открывая четвёртое соединение роли приложения.

## DNS и HTTPS — оставшийся внешний шаг

В зоне у **u1.hoster.by / u2.hoster.by** уже есть правильные A-записи abdrive.ru и www.abdrive.ru → **5.23.48.128**. Но родительская зона `.ru` при последней проверке продолжала делегировать домен на **ns1.hoster.by / ns2.hoster.by**, которые не обслуживают эту зону. Это может требовать изменения именно NS в настройках домена, а не повторного добавления A-записей.

Публичный DNS и HTTPS ещё не подтверждены. Сертификат abdrive.ru не выпускался. Подготовлен `deploy/abdrive/enable-https.sh` (копия уже на сервере: `/srv/abdrive/ops/enable-https.sh`): после правильного DNS он выпускает отдельный сертификат, включает HTTPS и переводит www на основной домен. Конфигурацию abcars.by он не меняет. Пока нельзя объявлять публичный запуск завершённым.

## Что нужно для следующих этапов

1. Исправить/дождаться подтверждения делегирования, включить HTTPS, проверить публичные ответы.
2. Получить реальные тарифы партнёров до Москвы, комиссию и сценарий оформления. Подключить российский расчёт к versioned offers, затем цены/сортировки/фильтры. До этого нет выдуманного итогового RUB-расчёта.
3. Получить данные оператора и публичные контакты; подготовить документы и версию согласия. Сейчас никакой чужой оператор не указан.
4. Явно настроить владельца Telegram, затем включить приём заявок: `ABDRIVE_PRIVACY_FILE`, `ABDRIVE_CONSENT_VERSION`, `ABDRIVE_TELEGRAM_BOT_TOKEN`, `ABDRIVE_TELEGRAM_CHAT_ID`. Форма сейчас скрыта, POST заявок недоступен; каталог остаётся рабочим.
5. Расширить российский FAQ, подготовить редакцию журнала и региональные инструменты. Подключить собственную аналитику/Вебмастер и расширять индексируемые страницы по мере наполнения.
6. Переносить общие улучшения в один репозиторий с раздельными выпусками; согласовать включение архитектурной основы в BY после завершения параллельных изменений. Не запускать BY-деплой из российской рабочей копии.
