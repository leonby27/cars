# abcars.by и abdrive.ru: состояние архитектуры

Обновлено 1 октября 2026 года. Российская версия подготовлена в отдельной рабочей копии `../abdrive-worktree`, чтобы не задеть параллельные изменения главной abcars.by. Это один Git-репозиторий и общие модули, а не второй независимый проект.

Код сохранён локальным коммитом в ветке `codex/abdrive-architecture-20261001`. В основной BY-ветке сохранены параллельные изменения; общий BY-деплой не выполнялся. Единственное намеренно оставленное изменение в AGENTS.md рабочей копии — инструкция соседней задачи о загрузке главной; она не включена в российский коммит.

## Уточнение владельца: сохраняем существующий продукт

Владелец подтвердил: ABDrive должен использовать тот же интерфейс и возможности, что действующий ABCars, с изменениями для России. Отдельная упрощённая композиция `src/abdrive/App.jsx` была ошибочным направлением и не считается выполнением переноса продукта. Её дальнейшее самостоятельное развитие прекращается.

Целевой путь — общий `src/App.jsx`, существующие компоненты и стили, профиль рынка и региональные модули. Самостоятельные выпуски, процесс RU, права базы и общие факты импорта сохраняются. Для этого не нужны две независимо развиваемые копии фронтенда.

Порядок исправления:

1. Согласовать формат каталога/карточки RU с существующим интерфейсом. Сейчас ответы RU (`cars`, `offer`) и BY (`items`, прежние ценовые поля) различаются; простая замена точки входа некорректна.
2. Вынести из общих экранов региональные цены, валюту/город, льготы, контакты, документы, SEO-тексты и аналитику. В существующем `App.jsx` остаются прямые BY-зависимости; подключать его к RU без адаптации нельзя.
3. Подключить RU к общей главной, каталогу, карточкам, быстрому просмотру, навигации и теме. Использовать существующие компоненты/стили, а не перерисовывать их отдельно.
4. Перенести избранное, аккаунт и сохранённые поиски с отдельными данными RU; региональные сервисы и журнал использовать с собственной редакцией и правилами.
5. Проверить обе сборки, контракты API и отсутствие BY-цен/контактов/счётчиков в RU. Выпустить только RU, затем проверить рабочие страницы BY и неизменность его процесса.

Это зафиксированное исправление направления, а не отчёт о завершённом переносе: опубликованный выпуск `20261001-audit` пока содержит прежний упрощённый интерфейс.

## Принятые решения

- Общий импорт и факты автомобилей; отдельные предложения, тексты, сервисы и пользовательские данные рынков.
- РФ: RUB, базовый город доставки Москва. Другие города подключаются с тарифами.
- Заявка приходит владельцу; он сам передаёт её выбранному партнёру.
- Общего флага «RU не готов» нет. Каталог работает независимо от будущих расчётов, документов и инструментов.
- Изменения BY не публикуются вместе с RU. Ранее работающий BY-процесс и бизнес-данные сохраняются.

Фото используют общий существующий публичный кэш. Текущая российская композиция переиспользует лишь небольшую часть общих компонентов. По уточнению владельца это недостаточно: её нужно заменить общим существующим интерфейсом, как описано выше. Полного переноса возможностей BY пока нет.

## Что установлено на сервере

- Сервер: 5.23.48.128, существующий Timeweb.
- Приложение: `/srv/abdrive/current` → `/srv/abdrive/releases/20261001-audit`.
- Закрытая конфигурация: `/etc/abdrive/environment`, root:abdrive, 0640. Секреты не копируются в код.
- База: `abdrive`, только новые таблицы `site_identity`, `leads`, `lead_notifications`, `market_offers`. Рабочие BY-записи не изменялись.
- Служба: `abdrive.service`, 127.0.0.1:8788; включён автозапуск. BY-служба не перезапускалась: PID 96469, старт 08:49:12 UTC.
- Отдельный HTTPS-хост nginx для abdrive.ru; HTTP и www перенаправляются на https://abdrive.ru. Конфигурация проверена перед плавной перезагрузкой nginx. Сертификат и приложение BY не менялись.
- Через запросы непосредственно к серверу подтверждены главная, каталог, карточка, порядок покупки, robots, sitemap, отдельный API. На проверке каталог содержал около 134 тысяч активных объявлений.
- Прямой запрос к каталогу не возвращает исходный payload, URL продавца или белорусскую цену. RU-роль не видит таблиц клиентов BY.
- В новой рабочей базе 0 заявок и 0 уведомлений: тестовые обращения туда не создавались, Telegram-сообщения не отправлялись.

При первом подключении выявлена ошибка проверки отсутствующей предыдущей версии в сценарии отката. Исправлена; повторный выпуск r2 успешно проверен. Она затронула только новый ABDrive-процесс. Ограничение в три соединения намеренное: диагностику прав выполняем через администратора в транзакции только для чтения, не открывая четвёртое соединение роли приложения.

## DNS и HTTPS — подключены 1 октября 2026 года

Родительская зона `.ru` теперь делегирует домен на **u1.hoster.by / u2.hoster.by**. Оба публичных резолвера, **1.1.1.1 и 8.8.8.8**, с сервера подтвердили abdrive.ru и www.abdrive.ru → **5.23.48.128**.

Выпущен отдельный сертификат Let's Encrypt для обоих имён, действующий до **30 декабря 2026 года**. Сертификат расположен в `/etc/letsencrypt/live/abdrive.ru/`; автоматическое продление включено. HTTPS, перенаправление HTTP и www, главная, каталог, карточка, FAQ, порядок покупки, robots и sitemap проверены. Системный DNS-кэш ещё хранит старый отрицательный ответ, поэтому проверки HTTPS выполнены с явным адресом сервера и обычной проверкой доверия сертификату, без отключения TLS-проверки. Глобальные настройки DNS не менялись.

Скрипт `deploy/abdrive/enable-https.sh` при старом локальном DNS-ответе требует совпадения ответов двух публичных резолверов. Обновлённая копия установлена в `/srv/abdrive/ops/enable-https.sh`.

Однократная проверка `dns-abdrive` завершена; после остановки автоматизация удалена по просьбе владельца. Приложение BY по-прежнему PID 96469 со стартом 08:49:12 UTC, без перезапусков; основные публичные страницы проверены после подключения HTTPS.

## Подробные карточки и общий поиск названий

Установлен выпуск `20261001-facts`, только ABDrive:

- Карточки показывают доступные сведения о топливе, объёме и мощности двигателя, приводе, коробке, кузове, цвете, батарее и запасе хода. Берутся только явно разрешённые поля; payload и белорусские суммы не выдаются пользователю.
- Данные конкретного объявления имеют приоритет для цвета; дизель не переименовывается в бензин, нулевой пробег сохраняется, неизвестные характеристики не придумываются. У электромобиля не появляются случайные поля бензинового двигателя.
- Показана дата обновления данных объявления по Москве; она не является обещанием текущего наличия. Фото можно открыть полностью через общий кэш оригиналов.
- Транслитерация выделена из ценового парсера в независимый общий модуль. Старый экспорт для BY сохранён. RU использует общий словарь марок и моделей, русские написания и исправление раскладки; порядок слов допускает «001 зикр». При распознанной марке исключены случайные варианты вроде Buick для «иьц» → BMW.
- Поиск названий не интерпретирует суммы в рублях по правилам BY. Старые параметры белорусской цены/квоты/возмещения отклоняются явно.
- Проверки: тестовые SQL-таблицы, поиск в реальном локальном каталоге, полный набор тестов, российская и белорусская сборки. На сервере подтверждены поиск BMW/Zeekr, подробные карточки и неизменность BY-процесса.

Аудит оставшихся связей: общий импорт и фото-кэш используются намеренно; общий словарь поиска больше не тянет ценовые правила BY. Российские цены, услуги, редакция журнала, аналитика и документы требуют собственных данных. Личный кабинет/избранное ещё не перенесены. Белорусские контакты, журнал, квота и сравнение рынков не публикуются в RU. Визуальная проверка по-прежнему остаётся владельцу.
