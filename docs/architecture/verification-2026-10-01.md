## Найдено и исправлено в ABDrive

1. Для выпуска и включения HTTPS добавлена одна отдельная блокировка ABDrive. Два запуска больше не могут одновременно переключать российский сайт.
2. Проверка выпуска следует перенаправлению HTTP → HTTPS и проверяет российский хост после включения сертификата. Для обновления сертификата задана проверка и перезагрузка nginx.
3. Ссылка на автомобиль в российском Telegram-сообщении сохраняет полный ID источника. Это исключает неоднозначность одинаковых числовых ID разных источников. Формат BY сохранён.
4. Приём заявок требует одновременно документа, версии согласия и явно настроенного Telegram-получателя. При отсутствующем документе или настройках отключается форма, каталог продолжает работать. Настройки BY не наследуются.
5. Неподдержанные значения сортировки, включая имена свойств прототипа, возвращают ошибку параметров до SQL-запроса.

Исправления проверены локально и установлены в ABDrive выпуском `20261001-audit`. Полный набор архитектурной ветки: 1 255 проверок прошли, 0 ошибок, 2 пропущены; сборка RU успешна. Реальная отправка Telegram не проверялась: получатель и документы ещё не заданы. Локально проверены сохранение заявки с очередью одной транзакцией, повтор отправки, конфликт запроса, повторная доставка и формат сообщения с подменённым транспортом.

## Проверка изоляции

- RU-роль видит только `catalog_listings`, `vehicles`, `listing_media`; подключение по умолчанию только для чтения, максимум 3 соединения, ограничение запроса 5 секунд.
- Заявки и очередь находятся в отдельной базе `abdrive`. Миграции RU ограничены её именем и проверкой принадлежности. Старые BY-миграции не запускались.
- Процесс RU работает отдельным пользователем на loopback-порту, с ограничениями памяти и CPU; каталог и сборки BY не используются как каталог выпуска RU.
- `/.env`, аккаунты/аналитика BY, белорусские инструменты и журнал через RU возвращают 404.
- Исходный payload, URL продавца и поле белорусской цены в публичный ответ карточки не попадают. Российская цена остаётся неопределённой до своего расчёта.
- Тестовые изменения базы ограничены PostgreSQL на loopback рабочей станции и временными схемами с откатом/удалением. Рабочие заявки не создавались.
- На момент проверки сервер имел около 1,3 ГБ доступной памяти и 49 ГБ свободного диска. Это запас текущего запуска, не оценка масштабирования под будущий трафик.
