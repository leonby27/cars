# Общий HTML-шаблон

Актуальное устройство `index.html`, проверено по реализации 19 октября 2026 года.
Пояснения для разработчиков хранятся здесь, а не в HTML и встроенных скриптах,
которые получают посетители. История прежних решений доступна в Git.

## Порядок метаданных

Сначала в head стоят charset и viewport, затем title, description, robots, canonical
и метаданные Open Graph/Twitter. Ссылки ресурсов и исполняемые скрипты идут после них.
Сервер вставляет SEO-теги в начало head; приложение сохраняет этот порядок при
смене маршрута и создании недостающих тегов. JSON-LD остаётся отдельным блоком.

## Ресурсы первого экрана

- Сохраняются ссылки на SVG, PNG и ICO, Apple Touch Icon и manifest.
- Обе части Manrope — кириллица и латиница — предзагружаются как шрифты с `crossorigin`.
- Тема устанавливается до первого отображения. Чтение localStorage защищено `try/catch`;
  если сохранённой доступной темы нет, используется системная.
- Стили и обработчик `.booting .seo-body` нужны запасной SEO-разметке. Они не скрывают
  штатную серверную разметку приложения. Через пять секунд класс загрузки и запасной
  первый экран снимаются даже при неудачном запуске приложения.

## Стили и данные готовых страниц

- Сборка помечает общий встроенный CSS атрибутом `data-page-css`. Сервер для готовой
  разметки и сборка главной оставляют в этом блоке правила, которые могут применяться
  к её классам. Сохраняются темы, состояния, медиа-запросы, шрифты и анимации;
  сложные селекторы сохраняются консервативно. Это отбор по разметке, не замер CSS coverage.
- Полная таблица стилей остаётся по своему хешированному адресу. Версия CSS-конвейера
  и списка классов включается в имя файла ещё на этапе Vite, вместе с хешем CSS. Она
  подключается после встроенного блока через существующий неблокирующий link и
  noscript-вариант. Сохраняются прежний итоговый порядок (общие срочные правила, затем отложенные)
  и оформление следующих
  переходов внутри сайта. Часть правил повторяется; общий объём холодной загрузки
  HTML + CSS может оказаться больше прежнего. Проверять реальную скорость отдельно,
  не выдавать уменьшение HTML за измеренное улучшение LCP.
- `window.__boot` со снимком данных стоит после содержимого root, перед закрывающим
  body. Модуль приложения отложенный, поэтому получает снимок до своего исполнения.
  Маленькие ранние скрипты темы и запросов остаются в head.
- Встроенные записи списка отбираются через явный набор полей в `bootCars`.
  Сохраняются все входы расчёта цены, нормализации, фильтров, фотографий, дат и
  ссылок. `_summary: true` заставляет быстрый просмотр запросить полную карточку.
  Данные API отдельных машин и структурированная разметка не сокращаются.
- Закрытое меню выбора страны — сосед H1, а не часть его содержимого. В H1 остаются
  название раздела и видимая кнопка страны; её доступное имя совпадает со словами
  на кнопке. Позиция меню вычисляется относительно прежнего якоря кнопки.

## Ранние запросы данных

- Запросы начинаются до запуска приложения и сохраняются в `window.__boot`.
- `/catalog` и все его вложенные разделы запрашивают загрузочный список из одной
  машины. Остальные маршруты используют существующую витрину из 60 автомобилей.
- Карточка машины отдельно запрашивает свой автомобиль по идентификатору.
- Справочник фильтров заранее запрашивается на главной, в общем каталоге и разделах
  по типу двигателя. Его ответ сохраняется рядом с обещанием запроса.
- При сетевой ошибке или HTTP 429/500/502/503/504 предусмотрены до трёх попыток.
  `Retry-After` учитывается полностью: число секунд или HTTP-дата. Без него действует
  короткая возрастающая пауза. Отклонение раннего обещания обработано до его чтения
  приложением, чтобы не создавать необработанную ошибку.
- Правила свежести ответов задаёт сервер.

## Счётчики

- Метрика, Google Analytics и Ahrefs сохраняют свои существующие исключения для
  внутренних страниц, локальных адресов, пометки `nocount` и автоматических заходов.
- `nocount=1` запоминает исключение в этом браузере; `nocount=0` снимает его.
- Загрузка библиотек ставится в общую очередь, которую обслуживает `src/counter-loader.js`.
  Просмотры и переходы приложения продолжают использовать существующие очереди.
- В Google Analytics автоматический page_view и рекламная персонализация отключены;
  просмотры отправляются явно.
- У Ahrefs автоматические просмотры отключены. Для проверки установки Ahrefs Site Audit
  есть отдельная ветка. При уходе во внутренний раздел отправка прекращается.
- `noscript` Метрики остаётся в body, а не в head.

## Безопасная правка

Сохранить порядок скриптов, ссылки ресурсов, селекторы, идентификаторы, параметры
счётчиков, метаданные, JSON-LD и данные гидратации. Не удалять вслепую все HTML-комментарии
из готовых страниц: React использует технические комментарии для границ и гидратации.
Лицензионные уведомления сторонних библиотек не относятся к поясняющим заметкам шаблона.

При очистке 19 октября удалены только шесть поясняющих HTML-комментариев и 56 комментариев
во встроенном JavaScript. Сравнение синтаксических деревьев всех скриптов до и после
подтвердило одинаковый исполняемый код; остальная разметка совпала с точностью до пробелов.
