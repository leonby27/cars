# Юридические документы abcars.by

Подготовлены 09.09.2026. Универсальная редакция по запросу владельца: без реквизитов и прямых контактов, с отсылкой к разделу «Контакты». Публичные пометки о проекте сняты; это не подтверждает юридическую готовность.

## Изученные источники

- MotorsGroup, условия: https://www.motorsgroup.by/polzovatelskoe-soglashenie
  Использована общая структура: сайт, справочная информация, обращения, отдельный договор, обязанности сторон.
- MotorsGroup, политика: https://www.motorsgroup.by/politika-konfidencialnosti
  Сопоставлены разделы о составе данных и целях. Не перенесены не относящиеся к abcars.by записи звонков, вакансии, доступ к микрофону и идентификаторы мобильных приложений.
- «Фронтир Авто», политика, 6 страниц PDF: https://f-avto.by/files/mail/privacy_policy.pdf
  Ориентир обычного документа: оператор, данные, права, обращения, защита.
- Закон Республики Беларусь № 99-З: https://etalonline.by/document/?regnum=h12100099
  Проверены статьи 9–15: трансграничная передача, права и порядок обращения.
- НЦЗПД: https://cpd.by/en/about-center/
  Проверены наименование надзорного органа и его полномочия по жалобам.

Текст написан самостоятельно под фактические функции проекта. Условия покупки не выдаются за договор или публичную оферту на поставку машины. Сроки исполнения запросов не подменяют сроки хранения данных.

## Что требуется для утверждения

1. Реальные наименование владельца, УНП, юридический адрес, рабочий email и способ подачи заявлений. В `src/company-data.js` сейчас явно указаны demo-реквизиты.
2. Цели, основания и конкретные сроки хранения по категориям, включая обращения, профиль, дополнительные паспортные поля, статистику и резервные копии. Нельзя обещать автоматическое удаление, которого нет.
3. Реальные юридические лица хостинга/аналитики/связи, страны обработки и основания трансграничной передачи.
4. Порядок согласия на аналитику и паспортные поля, отзыв согласия; проверка маскирования Вебвизора. Текущий интерфейс не содержит отдельного управления аналитическими cookie. Изменения согласий не входят в эту замену ссылок.

По запросу владельца `LEGAL_DRAFT = false`: PDF содержат только текст для посетителя, без внутренних замечаний. Пункты выше остаются открытыми. Статья 5 Закона № 99-З требует до получения согласия отдельно сообщить наименование и местонахождение оператора, цель, данные, срок и прочие предусмотренные сведения. Универсальная политика и ссылка на контакты эту обязанность не заменяют. Реальный канал для реализации прав также должен работать.

## Обновление

Единый текст: `src/legal-copy.js`. Генерация: `python3 scripts/generate-legal-pdfs.py` (Node.js, reportlab, шрифты DejaVu; при необходимости `LEGAL_PDF_FONT_DIR`). Результаты: `output/pdf/` для проверки и `public/documents/` для сайта. PDF хранятся в репозитории; Python не нужен серверу или обычной сборке.

После изменения текста заново создать PDF, проверить страницы и собрать сайт. Все ссылки используют `src/legal-documents.js`, `target="_blank"`, без `download`. Старые адреса перенаправляются на PDF в Vite и nginx. При последующей публикации необходимо отдельно синхронизировать `deploy/nginx-abcars-site.conf`, проверить nginx и перезагрузить конфигурацию согласно AGENTS.md.
