# Автоматические заходы в аналитике

Изменения подготовлены 30.10.2026. Владелец разрешил commit, push и публикацию всех
подготовленных изменений 30.10.2026; выпуск выполняется штатной командой deploy.

## Новые события

Существующие проверки известных роботов, webdriver, собственных проверок и источника
запросов сохранены. Дополнительно явный бренд `HeadlessChrome` проверяется в
`navigator.userAgentData.brands` и серверном заголовке `Sec-CH-UA`, даже если
User-Agent представляется обычным Chrome. Та же проверка применяется в резервном
worker, Метрике, GA4 и Ahrefs. Проверка установки Ahrefs по-прежнему видит тег без
регистрации посещения.

Для `human_action` принимаются только доверенные браузерные события ввода на
видимой странице: мышь, касание, клавиша, колесо, click (включая активацию через
вспомогательные технологии). Искусственный `dispatchEvent` игнорируется и не
снимает слушатели: последующее настоящее действие может подтвердить посещение.
Один `scroll` не подтверждает действие, поскольку его создают также `scrollTo`,
восстановление позиции и другие функции сайта. При ручной прокрутке действие
подтверждают события колеса, касания, клавиши или нажатия мыши.

Таймер пребывания остаётся слабой отметкой `human` и не устанавливает
`human_action`. Короткий заход, чтение без ввода, пустая выдача, прямой источник,
версия Chrome, страна, отсутствие Client Hints или недоступность этих данных не
служат новыми основаниями исключения. Режим «Все» сохраняет обычные посещения без
действий. Прежнее правило режима «С действиями» по всей истории посетителя
сохранено.

Доверенный ввод не гарантирует человека: автоматизация через протокол браузера
способна создавать такие же события. Если она также скрывает явные маркеры, эти
правила не обеспечивают её безошибочное распознавание. Общие блокировки по
неподходящим фильтрам, IP, версии браузера и отсутствию действий не добавлялись.

## Два разобранных исторических события

`server/analytics-reviewed-automation.mjs` содержит только идентификаторы двух
событий из проверки MG HS и Panamera PHEV. Основания: первое открытие уже с
неподходящими условиями, один просмотр у каждого visitor_id, одинаковая подпись
macOS/Chrome 145 и серия перебора похожих условий с разных IP. Совокупность
признаков даёт высокую вероятность автоматизации; оператор не установлен.

Исключение действует по точному event_id в отчётах, графиках, сравнении и
непрочитанных счётчиках, а также при подтверждении действия и определении
повторного посещения. Исходные строки не удаляются и не изменяются. Посетитель,
IP и URL не заблокированы; другое событие с теми же условиями или последующее
действие того же посетителя остаётся доступным. Исключение можно отменить,
убрав конкретный идентификатор из списка. Это индивидуальная корректировка,
а не правило автоматического распознавания будущих посещений.

Первичная диагностика сохранена в родительской рабочей папке:
`research/analytics-2026-10-30-filtered-direct-visits.md`.

## Проверка

- `npm test`: 1579 пройдено, 5 пропущено, ошибок нет.
- `node tests/analytics-interaction.browser.mjs`: шесть браузерных сценариев;
  все запросы перехвачены локальными ответами, боевые события не отправлялись.
- Дополнительная проверка SQL отчётов в PostgreSQL: контрольные строки переданы
  через CTE в транзакции READ ONLY. Таблица заходов и график сохраняют 3 обычных
  посещения в «Все» и 2 посещения с действиями; два разобранных события исключены.
  Новое действие посетителя из исключённого события сохраняется и не получает
  ложную отметку повторного захода. Постоянные данные не изменялись.

Для этих правил аналитики миграции и исправления каталога/бизнес-записей не требуются.

## Дополнительная историческая очистка 30.10.2026

После отдельной просьбы владельца исключить накопленные автоматические заходы
проверены 33 562 события с 26 августа и сохранившиеся nginx-журналы с 16 октября.
По точному сопоставлению запросов с событиями отобраны ещё 53 одиночных захода
22–30 октября из той же массовой серии перебора фильтров. У каждого было не менее
двух кузовов в исходном URL, один page_view за всю историю visitor_id, прямой
источник, однозначно сопоставленный первый GET и отсутствие других переходов и
POST за пределами аналитики. Версия браузера и пустая выдача по отдельности
основаниями исключения не являлись. Два контрольных мобильных посещения с
фильтрами сохранены. Более старая история без журналов и неоднозначные случаи
не исключались по предположению.

53 полных исходных записи атомарно перенесены из `analytics_events` в
`analytics_excluded_events`: `event_payload` содержит точный исходный ряд,
`batch_id`, `reason`, `evidence` и `excluded_at` объясняют исключение. IP в эту
таблицу не переносились. Перенос действует сразу во всех существующих отчётах;
код приложения и рабочая сборка не менялись. Он дополняет два прежних исключения
по event_id: всего из этой проверенной серии исключены 55 заходов.

Таблица посещений, график, посетители и просмотры страниц изменились согласованно.
