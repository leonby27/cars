# Справочник мощности для предварительной цены, 01.10.2026

Владелец разрешил оценки по справочнику: окончательную цену клиенту считают вручную. Справочник содержит 29 правил; это не база выданных ЭПТС и не юридическая гарантия мощности.

Источники и тип доказательства:

- [BYD Song Pro DM-i, руководство, стр.365](https://www.byd.com/material/domestic-official/user-manual/dynasty/宋Pro%20DM-i智驾版1112.pdf): TZ210XYB, номинальная 55 кВт, пиковая 120 кВт. Используем как аналог для BYD с этим кодом, одним передним мотором и совпадающим пиком. Номинальная мощность не объявляется документальной 30-минутной.
- [BYD ATTO 3, руководство, стр.254](https://www.bydauto.co.nz/storage/uploads/c6cdc150-d114-4d0b-8be0-d0374df5edfb/ATTO-3-Owner%27s-Manual-RHD-Chinese_NZ_08_2022.pdf): TZ200XSQ, номинальная 65 кВт. Аналог ограничен электрической схемой BYD, передним одиночным мотором и пиком 150 кВт.
- [Tesla, официальные 30-минутные мощности](https://www.tesla.com/de_at/support/maximum-30-minute-power-values): Model 3 и Model Y, отдельные поколения, привод и комплектации. Передняя/задняя мощности суммируются. Европейская спецификация служит оценкой для китайского/корейского ввоза; значение документа конкретного авто имеет приоритет. Если комплектация отсутствует, берутся совместимые варианты. У новых заднеприводных Model Y объединены 110–114 кВт.
- [White Broker, собственная подборка вариантов EV](https://whitebrokerdv.ru/articles/elektromobili-pod-lgotnyj-utilizacionnyj-sbor-2026): двенадцать правил Qin Plus EV, Dolphin, Seagull, E2, IONIQ 5, Niro, Kona. Подборка импортёра, а не проверенные нами сертификаты. Используется совпадение модели, года, привода, батареи и пика. Для батареи допуск 0,15 кВт·ч, пика 1 кВт для округления источника. Отсутствующий пик допустим только у записи с моделью, батареей и приводом; известный противоречащий пик запрещает совпадение. Это позволяет считать корейские объявления без указанной мощности. Месяц выпуска не известен — годы в этих записях включены целиком.

Не применяем общий коэффициент 45%: [KAD описывает отдельную практику](https://www.kad-autoconsult.ru/statyi/formula-30-minutnoy-moshchnosti-gibridy-elektro.html), но это не универсальная характеристика. Без записи остаётся прежний широкий диапазон. Пределы годов у открытых актуальных моделей ограничены 2026 годом. Перенос номинальных значений по идентичному мотору между моделями — явно принятое допущение ABDrive.

Добавление: новая запись в `config/ru-power-reference.mjs`, источник с типом доказательства, ограничения модификации, контрольный пример, затем повышение `RU_POWER_REFERENCE_VERSION`. Не вносить оценку в `motorThirtyMinutePowerKw`. Это поле зарезервировано для исходных данных документов.
