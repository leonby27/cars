# Системная проверка расчётов ABDrive — 02.10.2026

## Причина

Существующий справочник `config/korea-specs/*.json.gz` (19 марок, сбор 29.09.2026) использовался при импорте, но не при российском расчёте уже импортированных объявлений. Импорт сохранял мощность только при однозначном совпадении. У гибридов общее `summary.horsepower` означает системную, а не отдельную мощность ДВС.

Полный исходный проход по 132 856 активным объявлениям: 64 169 расчётов одной суммой, 31 244 диапазона, 37 443 без расчёта. Причины отсутствия: двигатель 28 197, схема гибрида 6 157, электромотор 2 900, год 189. Проверялись все активные строки `catalog_listings`, а не только примеры пользователя.

## Исправление

- При расчёте Encar используется существующий каталог модификаций. Учитываются модель, поколение, год, объём, топливо, привод и известная комплектация. PHEV не смешивается с явно указанным HEV.
- Мощность ДВС берётся из отдельного раздела двигателя; системная мощность гибрида не подставляется вместо неё. Пиковая электрическая мощность используется только как граница, не как документальная 30-минутная.
- При нескольких подходящих модификациях сохраняются минимальная и максимальная мощности. Если обе дают одну сумму налогов, отображается одна цена.
- Региональные заводские данные уточняют Tucson NX4, Ray, Elantra CN7 и K8. Известные исходные значения имеют приоритет. K8 до/после рестайлинга различается по исходному названию серии.
- `AT` распознаётся как автоматическая коробка параллельного гибрида; явная последовательная схема имеет приоритет.
- Справочник номинальной мощности расширен для Li ONE/L6/L7/L8/L9 и семейств двигателей BYD. Заводская номинальная мощность остаётся оценкой по аналогу и никогда не заполняет поле документальной 30-минутной мощности.
- Исправлена подсказка: диапазон ДВС больше не объясняется мощностью электромоторов.
- Общие импортированные факты, BY-расчёты и клиентские данные не изменяются.

## Постоянный контроль

Каждое обновление российского индекса цен сканирует все активные объявления и одновременно сохраняет `coverage` в `/var/cache/abdrive/price-index.json`. Дополнительного полного запроса к БД не требуется. Отчёт содержит число цен/диапазонов/пропусков и группы проблемных модификаций с количеством, причинами и тремя примерами. Продавцы и контакты в отчёт не включаются.

Чтение готового отчёта:

```sh
npm run audit:ru-prices -- --file /var/cache/abdrive/price-index.json --out /tmp/abdrive-pricing-coverage.json
```

Широким считается диапазон более `max(250 000 ₽, 10% нижней цены)`. Это внутренний критерий очереди проверки, а не новый блок на сайте. Для устранения группы нужно уточнить правила сопоставления или добавить источник с границами поколения/привода/мотора/батареи, затем проверить полный отчёт. Не требуется отдельная правка объявления по ID.

Оставшиеся неизвестные варианты сохраняют диапазон либо отсутствие расчёта; универсальных коэффициентов мощности нет. Покрытие конкретного развёртывания проверяется по версии и дате отчёта, оно не означает подтверждение расчёта для VIN.
