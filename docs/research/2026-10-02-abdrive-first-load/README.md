# ABDrive: первое открытие, 02.10.2026

До исправления: `/` ждёт `catalog.list`, метаданные и `modelFacts`, затем рисует всю страницу заново при каждом запросе. Три запроса с самого сервера к RU приложению: 3,55 / 3,77 / 3,77 с до первого байта. BY после прогрева: 0,045 с. Внешняя единичная проба ненадёжна для сравнения из-за изменчивого TLS, поэтому использованы также серверные замеры.

HTML главной: 1 376 540 байт. Данные 60 карточек повторяются в `catalogValue.items`, `catalogValue.cars` и `homeShowcase`, вместе с полными галереями. Все публичные ресурсы идут через Node, конкурируя с фоновым пересчётом цен при CPUQuota 50%.

Изменения:

- Отдельный сохранённый снимок главной готовится до переключения релиза, вместе с ценами. Содержит 20 карточек и до пяти фотографий, факты каталога и модельные ссылки; без повторного `catalogValue` и `api`.
- Главная не ждёт живых запросов. Снимок читается при запуске, первая разметка готовится до начала приёма запросов. HTML используется повторно до обновления снимка или смены дня. Страницы с поисковой строкой сохраняют собственное состояние URL.
- Обновление раз в пять минут в фоне с сохранением последнего успешного результата и паузой между повторными попытками. При отсутствующем снимке остаются заголовок, поиск и скелеты блоков. Снимки другой версии расчёта или старше суток не используются для начальных цен.
- Браузер обновляет витрину и модели после гидратации. Ошибка каталога в RU оставляет главную и сохранённые карточки, показывает повторную попытку внутри каталога.
- Публичные стили, скрипты, шрифты и иллюстрации отдаёт nginx напрямую; сборка готовит Brotli. Поведение BY не меняется.
- Входной модуль RU, как BY, даёт готовой разметке отрисоваться перед загрузкой React; поля текстов, не нужные клиенту, исключены тем же существующим плагином.

На одинаковом исходном снимке HTML сократился до 355 312 байт (−74%). Локальный первый рендер 26 мс, повторная отдача готового HTML менее 1 мс. Это замеры генерации/размера, не браузерный LCP; визуальная проверка не выполнялась согласно инструкции проекта.

Тесты проверяют немедленный ответ при зависшем каталоге, повторное использование HTML, сохранение URL, RUB-цен и модельных ссылок, повреждённый/несовместимый снимок, восстановление и сохранение данных после ошибки.
