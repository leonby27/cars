# Страны в аналитике

В «Заходах» на компьютере и телефоне используются 64 локальных SVG-флага:
Европа, включая малые государства и европейские территории, страны бывшего СССР,
США и Канада. Название страны доступно в общей подсказке по наведению, фокусу или
нажатию. Для других известных стран остаётся значок глобуса с точным названием.

Страна определяется сервером при записи события; переданный браузером код
игнорируется. В событиях хранится только код страны, IP посетителя не сохраняется.
Старые значения `other` означают «Другая страна», отсутствующее значение — «Страна
не записана». В пределах одного захода точный сохранённый код имеет приоритет
перед старым `other`; неизвестные исторические страны не восстанавливаются догадками.

`npm run countries` атомарно обновляет таблицу `country_ranges` из официальных
delegated-extended файлов RIPE NCC, ARIN, APNIC, AFRINIC и LACNIC. Это страна
регистрации сети, а не гарантированное физическое положение человека. Для VPN и
прокси видна страна выходной сети. Неопознанные сети сохраняются как `other`.
Успешная загрузка всех пяти источников, минимумы по источникам и основным странам,
а также проверка объёма относительно прежней таблицы обязательны до замены.
Ошибка загрузки или записи сохраняет прежнюю таблицу.

При выпуске этих изменений нужно один раз выполнить `npm run countries` с
окружением соответствующего сайта, чтобы вместо прежнего справочника BY/RU
появился мировой. Затем требуется перезапуск API, чтобы очистить часовой кэш
прежних кодов стран. После этого справочник обновляет существующий еженедельный
`abcars-ranges.timer`. Схема базы не меняется. При переустановке служебного файла
`abcars-ranges.service` меняется только поясняющий комментарий.

Правила географического доступа, CAPTCHA и блокировки стран остаются отдельной
системой и этим изменением не затрагиваются.
